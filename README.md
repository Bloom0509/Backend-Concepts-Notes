# Backend Concepts Notes

A personal study and revision repository for backend engineering fundamentals, practical concepts, and interview preparation.

## Study materials

- **[Backend Fundamentals Notes](./Backend-Fundamentals-Notes.md)** — detailed notes for learning and revising core backend engineering concepts.
- **[Roadmap](./Roadmap.md)** — a structured path to guide your backend learning.
- **[Backend Engineering Revision Table](./backend-engineering_RevisionTable.md)** — a quick-reference table for revisiting key concepts.

## How to use this repository

1. Follow the roadmap to choose what to study next.
2. Use the fundamentals notes to understand each topic.
3. Review the revision table when refreshing concepts or preparing for interviews.
4. Add examples, diagrams, and lessons learned as your understanding grows.

This repository is maintained as personal study material. The goal is to build strong fundamentals, connect concepts to real-world backend systems, and make revision easier over time.
